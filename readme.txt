Artistic hand-painted brush stroke CTA buttons and creative headings for Elementor.

== Description ==

Painter Creative Elementor Widgets adds highly customizable, artistically styled Elementor widgets for hand-painted brush-stroke Call-to-Action (CTA) buttons and creative headings.

Developed specifically to meet bespoke client website design requirements where native Elementor widgets and existing marketplace plugins fell short. Designed to reproduce hand-painted service contractor banners (like paint roller CTA banners) with pixel precision while allowing designers to customize every brush edge, layer, paint roller graphic, and responsive behavior without writing custom CSS.

= Features =
* Creative Painter Button with organic brush edges and attached paint roller graphic.
* Creative Painter Heading with full paint background and semantic H1-H6 SEO tags.
* 9 built-in vector paint brush shapes (including Roller Stamp & Bristle Stroke).
* Multiple paint roller models (Square Arm Option 1, Offset S-Curve Option 2, etc.).
* Color pickers for paint, sleeve, cap rings, and synchronized hover transitions.
* Complete Elementor responsive controls and instant canvas live preview.
* GPU-accelerated micro-animations (Lift, Press, Paint Scale, Skew).
* Respects `prefers-reduced-motion` for accessibility.
* Zero external bloat (No jQuery or heavy animation libraries; pure inline SVG + CSS variables).

== Installation ==

1. Upload `painter-creative-elementor-widgets` to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Make sure Elementor is installed and activated.
4. Open the Elementor editor and search for "Painter Creative Widgets".

== Frequently Asked Questions ==

= Does this require Elementor Pro? =
No. It works seamlessly with both Elementor Free and Elementor Pro.

= Can I use my own custom SVG shape? =
Yes. Both widgets include a "Custom SVG" shape mode that safely parses and sanitizes your custom vector SVG.
